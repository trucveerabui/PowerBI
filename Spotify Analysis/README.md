# Spotify Dashboard

This project looks at music streaming data using an interactive Power BI dashboard that focuses on the artist. Users can pick any artist and instantly see updated results, with charts and text changing in real time to match the selected artist.

The dashboard makes it easy to explore an artist’s key numbers, trends, and comparisons in one place. By combining interactive visuals with dynamic text, the report turns raw data into clear, personalized insights.
